## About the Project

**Mobilix** is a dedicated web platform built to streamline vehicle hiring, local transit, private airport transfers, and luggage transportation services across Kwale County. It provides users with a seamless digital booking experience, connecting travelers and locals with reliable vehicles and transit solutions.

---

## Key Features

- **Vehicle Hiring & Rentals:** Browse and book available vehicles for flexible hire periods.
- **Private Airport Transfers:** Hassle-free reservations for airport pickups and drop-offs.
- **Local Transit & Luggage Logistics:** Efficient regional transportation and baggage handling management.
- **Modern UI:** Built with Vite and React for high performance and smooth user interactions.
- **Secure Backend API & Database:** Powered by Node.js, Express, and PostgreSQL to reliably handle user records, fleet catalogs, and bookings.
